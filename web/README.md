# web

The small React frontend: sign-in, document list, upload, document view with comments and annotation pins, share dialog. Built to static files and served by its own container (Nginx) behind the Ingress. It holds no secrets and talks to the API over `/api` and a WebSocket.

Kept deliberately small; the course grades the cloud work, the frontend exists so the demo is visible.
