## What we discussed

- **Which project.** Five course ideas. A GitHub clone, inventory management and a scientific data repository were set aside; the content sharing and collaboration platform gives a clear demo and real cloud work.
- **Hardest part.** Live commenting by several people at once: how to keep concurrent edits from corrupting the document state is the open design question.
- **Link sharing** has to stay restricted to the people it was shared with, which ties it to role-based permissions.

## Decisions

1. **Project:** Content Sharing and Collaboration Platform (course idea 3).
2. **Scope:** upload documents, share them directly or by link, comment on them live with @-mentions. Sized to finish on time, not every key feature on the course page.
3. **Roles:** Owner, Collaborator, Viewer.
4. **Versions:** every file and edit is timestamped so history can be shown and reverted.
5. **Proposal** drafted in the shared Google Doc; everyone commits to the repo as they work so contribution shows in the history.
6. **Weekly meeting** Saturdays.
