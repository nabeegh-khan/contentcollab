# Meeting 2, Saturday 17 October 2026

Teams, 3:30pm, 40 minutes. Nabeegh, Milton, Jyotiraditya, Eyrika. We reacted to the draft architecture and plan in the repo.

## What we discussed

- **Kubernetes or Docker Swarm.** Kubernetes gives autoscaling and persistent volumes built in but isn't covered in lectures yet; Swarm is simpler. Kubernetes, with Swarm as the fallback.
- **Live co-editing** needs a conflict-resolution engine and is a product of its own, so the scope is a review tool instead.
- **Frontend.** A small React app makes the demo something the audience can watch; the grade sits on the backend and cloud work, so it's under-promised in the proposal.
- **Bulk import** from a bucket or shared folder would run in a background worker so the API never stalls. Kept as planned work.
- **Cost** of about $40 a month while the cluster runs, split four ways.

## Decisions

1. **Orchestration:** Kubernetes on DigitalOcean (DOKS), proven on minikube first; Docker Swarm as fallback.
2. **Scope:** upload, version history, sharing, comments, pins, @-mentions, live updates. No live text editing.
3. **Frontend:** one small React app in its own container.
4. **Content in:** manual upload is the core; bulk import if time allows.
5. **How we work:** one Issue per task, one branch and pull request per Issue, one reviewer, squash and merge. Everyone reviews everyone else's work.
6. **Cost:** one DigitalOcean account hosts; the others e-transfer their share.
7. **Proposal:** drafted in the Google Doc; each settled section is moved by its owner into `docs/PROPOSAL.md`.
8. **Timeline:** features land by the 15 and 22 November checkpoints; the last days are for review, testing and the demo rehearsal.
