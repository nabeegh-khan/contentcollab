ContentCollab is an application that makes it easier for remote professionals and industry teams to review documents together. 

Users upload a PDF, image, or document and share it with other users either directly or through a link (similar to Google Drive). Users can comment and mention other users - these appear live for anyone on the document. 

Our application uses React for the web client, DigitalOcean Kubernetes for the containers, and PostgreSQL on persistent DigitalOcean volumes and Spaces object storage for the files.
