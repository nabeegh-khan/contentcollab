## Where the build differs from the proposal

- Monitoring: the proposal names Datadog for dashboards and container logs. The agent was dropped (ARCHITECTURE D17, D18; the memory limit that decided it was lifted by the node rebuild, D19), and the cluster runs Prometheus, kube-state-metrics and Grafana instead (#112), with DigitalOcean alerts (#62), `/metrics` and JSON request logs (#102).
- Pins: stored with each comment, not yet drawn (D28 Limits).
- Live text editing stays out of scope (D3).
